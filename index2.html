1. blokk – Bevezetés, címzés alapjai (2×45’)

1. óra: Miért van szükség IPv6-ra?

  • IPv4 kimerülése (tények, idővonal: IANA 2011, RIR-ek kimerülése)
  • NAT, CGNAT problémái (játékok, P2P, port forwarding)
  • IPv6 előnyei: hatalmas címtér (2128), nincs szükség NAT-re, egyszerű fejrész, beépített IPsec, SLAAC
  • Tévhitek eloszlatása: „bonyolult” – valójában logikusabb, „nem kompatibilis” – duál stack létezik, „lassabb” – gyorsabb router feldolgozás

2. óra: IPv6 cím felépítése, rövidítés, tömörítés

  • 128 bit = 8×16 bit = 32 hexa karakter; csoportosítás kettősponttal
  • Rövidítési szabályok: (1) vezető nullák elhagyása, (2) :: egyszeri használata
  • Speciális címer: ::1 (loopback), :: (meghatározatlan), ::ffff:192.0.2.1 (IPv4 leképzett)
  • Gyakorló feladatlap (tömörítés, kiterjesztés, hibás címek felismerése)

Gyakorló feladatlap (minta):

Eredeti címTömörített cím
2001:0db8:0000:0000:0000:0000:0000:00012001:db8::1
fe80:0000:0000:0000:0200:ff:fe00:1234fe80::200:ff:fe00:1234

Házi feladat: Tömörítsd a saját IPv4 címedet IPv4-leképezett formátumba (::ffff:192.168.1.100), majd tömörítsd tovább.

2. blokk – Címtípusok és alhálózatképzés (2×45’)

3. óra: IPv6 címtípusok

  • Unicast: Global Unicast (2000::/3), Unique Local (fd00::/8), Link-Local (fe80::/10) – mindegyikhez példák
  • Anycast: egy a legközelebbihez (pl. root DNS szerverek)
  • Multicast: ff00::/8 – fontos csoportok: ff02::1 (minden node), ff02::2 (minden router)
  • Link-Local címek automatikus létrejötte, szerepük (alapértelmezett gateway, RA-k küldése)

4. óra: Prefixek és alhálózatképzés

  • CIDR jelölés, ajánlott /64 a legtöbb hálózatban (SLAAC miatt)
  • Számítás: 2(új_prefix - régi_prefix) alhálózat
  • Gyakorlat: /48-ból /64-ek képzése (65536 db)
  • Alhálózati tervező táblázat kitöltése

Alhálózati tervező táblázat (minta):

Házi feladat: Egy cég megkapta a 2a01:1234:abcd::/48 címtartományt. Tervezz meg 8 különböző /64-es alhálózatot.

3. blokk – Duál stack, statikus IPv6 routing (2×45’)

5. óra: Duál stack konfigurálása

  • Duál stack elve: IPv4 és IPv6 együtt fut, alkalmazás preferencia (Happy Eyeballs)
  • Topológia: 2 router (R1, R2), 2 PC (PC1, PC2) pont-pont kapcsolattal
  • Router konfiguráció (Cisco): ipv6 unicast-routing, interfészen ipv6 enable és ipv6 address
  • PC konfiguráció (Windows/Linux) – statikus IPv6 cím és alapértelmezett útvonal
R1 (Cisco):
enable
configure terminal
ipv6 unicast-routing
interface g0/0
 ip address 10.0.1.1 255.255.255.0
 ipv6 enable
 ipv6 address 2001:db8:1::1/64
 no shutdown
interface g0/1
 ip address 10.0.12.1 255.255.255.0
 ipv6 enable
 ipv6 address 2001:db8:12::1/64
 no shutdown

PC1 (Windows):
netsh interface ip set address "Ethernet0" static 10.0.1.2 255.255.255.0 10.0.1.1
netsh interface ipv6 set address "Ethernet0" static 2001:db8:1::2/64
netsh interface ipv6 add route ::/0 "Ethernet0" 2001:db8:1::1

6. óra: Ping6, traceroute6, statikus routing

  • ping6, tracert -6 (Windows) / traceroute6 (Linux)
  • Statikus útvonalak: ipv6 route 2001:db8:2::/64 2001:db8:12::2
  • Ellenőrzés: show ipv6 route, show ipv6 neighbors

4. blokk – SLAAC mélyen (2×45’)

7. óra: SLAAC elmélet és folyamata

  • Automatikus, állapotmentes címkonfiguráció (Stateless Address Autoconfiguration)
  • Lépések: Link-Local generálása → DAD → RS → RA → GUA előállítása
  • ICMPv6 típusok: RS(133), RA(134), NS(135), NA(136)
  • EUI-64 címképzés (MAC → 64 bit) és véletlen címek (RFC 7217) – adatvédelem
  • RA flag-ek: A (autonomous), M (managed), O (other) – kombinációk: tiszta SLAAC, SLAAC + állapotmentes DHCPv6, állapotfüggő DHCPv6

8. óra: SLAAC konfigurálás és ellenőrzés (gyakorlat)

  • Router konfiguráció: ipv6 unicast-routing + interfészen /64 cím (RA automatikus)
  • PC beállítása automatikus címzésre (Windows: ipconfig /renew6, Linux: accept_ra=1)
  • Ellenőrzés: ip -6 addr show, show ipv6 neighbors
  • Wireshark bemutató: RS, RA, NS, NA csomagok rögzítése
Router (Cisco):
ipv6 unicast-routing
interface g0/0
 ipv6 enable
 ipv6 address 2001:db8:1::1/64
 no shutdown

PC (Windows):
netsh interface ipv6 set interface "Ethernet0" routerdiscovery=enabled
ipconfig /release6
ipconfig /renew6
ipconfig    # ellenőrzés

5. blokk – Összefoglaló gyakorlat és mérés (2×45’)

9. óra: Komplex gyaklati feladat

Topológia: 3 router (R1,R2,R3), 2 switch, 4 PC (PC_A, PC_B, PC_C, PC_D).

IPv6 címzési terv:

  • R1–R2: 2001:db8:ab::/64 (R1: ::1, R2: ::2)
  • R2–R3: 2001:db8:bc::/64 (R2: ::1, R3: ::2)
  • LAN1 (R1): 2001:db8:1::/64 – R1 gateway: ::1, PC_A és PC_B SLAAC
  • LAN2 (R3): 2001:db8:3::/64 – R3 gateway: ::1, PC_C: ::10, PC_D: ::11 (statikus)

Feladatok:

  1. Router interfészek konfigurálása (IPv4 opcionális).
  2. ipv6 unicast-routing minden routeren.
  3. Statikus IPv6 útvonalak felvétele (LAN1 ↔ LAN2).
  4. SLAAC beállítása a LAN1-en (PC_A, PC_B automatikus cím).
  5. Statikus címek a LAN2-n (PC_C, PC_D).
  6. Ping tesztek: PC_A → PC_C, PC_B → PC_D, PC_A → R2 link-local címe.
  7. Screenshot készítése show ipv6 route (R1) és ip -6 addr show (PC_A) kimenetekről.

Pontozás (100 pont): Router interfész (15) + routing be (5) + statikus útvonal (20) + SLAAC (15) + statikus PC (10) + ping (15) + screenshot (10) + elmélet (10).

10. óra: Bemutatás, hibaelhárítás, értékelés

  • 2-3 csapat bemutatja a megoldását (topológia, routing, SLAAC, sikeres ping).
  • Közös hibaelhárítás egy előre elrontott konfiguráción (pl. hiányzó ipv6 unicast-routing, rossz statikus útvonal, RA suppress).
  • Írásbeli gyorsteszt (5-10 kérdés).
  • Értékelés, jegyek közlése, zárás.

4. Táblai vázlat (oktatói segédlet az 1. órához)

IPv6 cím: 128 bit = 16 bájt = 32 hexa
Forma: XXXX:XXXX:XXXX:XXXX:XXXX:XXXX:XXXX:XXXX

Példa:
2001:0db8:85a3:0000:0000:8a2e:0370:7334

Rövidítés:
1. Vezető nullák elhagyása:
   0db8 → db8, 0000 → 0, 0370 → 370
   → 2001:db8:85a3:0:0:8a2e:370:7334
2. Egymás utáni nullás mezők tömörítése (::):
   2001:db8:85a3::8a2e:370:7334

Szabály: :: csak egyszer!

Speciális:
::1          = localhost
::           = meghatározatlan
::ffff:192.0.2.1 = IPv4 leképzett
