1. blokk – Bevezetés, címzés alapjai (2×45’)

📘 1. óra: Miért van szükség IPv6-ra?

  • IPv4 kimerülése (IANA 2011, RIR-ek kimerülése), NAT és CGNAT hátrányai
  • IPv6 előnyei: 2128 cím, nincs NAT, egyszerű fejrész, beépített IPsec, SLAAC
  • Tévhitek eloszlatása: „bonyolult” → logikusabb; „nem kompatibilis” → duál stack; „lassabb” → gyorsabb router feldolgozás

✏️ 2. óra: IPv6 cím felépítése, rövidítés, tömörítés

  • 128 bit = 8×16 bit → 8 darab hexa csoport kettősponttal
  • Szabályok: vezető nullák elhagyása, :: egyszeri használata
  • Speciális címek: ::1, ::, ::ffff:192.0.2.1

Gyakorló feladatlap (minta):

Eredeti címTömörített cím
2001:0db8:0000:0000:0000:0000:0000:00012001:db8::1
fe80:0000:0000:0000:0200:ff:fe00:1234fe80::200:ff:fe00:1234

🏠 Házi feladat: Tömörítsd a saját IPv4 címedet IPv4-leképezett formátumba (::ffff:192.168.1.100), majd tömörítsd tovább!

2. blokk – Címtípusok és alhálózatképzés (2×45’)

🎯 3. óra: IPv6 címtípusok

  • Unicast: Global Unicast (2000::/3), Unique Local (fd00::/8), Link-Local (fe80::/10)
  • Anycast: egy a legközelebbihez (pl. root DNS)
  • Multicast: ff00::/8 – ff02::1 (minden node), ff02::2 (minden router)
  • Link-Local automatikusan generálódik, szerepe: alapértelmezett gateway, RA küldés

📐 4. óra: Prefixek és alhálózatképzés

  • CIDR jelölés, ajánlott /64 a legtöbb LAN-ban (SLAAC miatt)
  • Alhálózatok száma: 2(új_prefix - régi_prefix)
  • Példa: /48-ból /64 → 216 = 65536 alhálózat

Alhálózati tervező táblázat (minta): 2001:db8:abcd::/48 → /64-ek

#/64 prefixHálózati címGateway

22001:db8:abcd:2::/642001:db8:abcd:2::2001:db8:abcd:2::1
🏠 Házi feladat: Tervezz 8 /64-es alhálózatot a 2a01:1234:abcd::/48 tartományból.

3. blokk – Duál stack, statikus IPv6 routing (2×45’)

⚙️ 5. óra: Duál stack konfigurálása (routerek, PC-k)

  • Duál stack = IPv4 + IPv6 együtt fut, alkalmazás preferencia (Happy Eyeballs)
  • Topológia: R1 – R2, PC1–R1, PC2–R2
R1 (Cisco):
enable
configure terminal
ipv6 unicast-routing
interface g0/0
 ip address 10.0.1.1 255.255.255.0
 ipv6 enable
 ipv6 address 2001:db8:1::1/64
 no shutdown
interface g0/1
 ip address 10.0.12.1 255.255.255.0
 ipv6 enable
 ipv6 address 2001:db8:12::1/64
 no shutdown

PC1 (Windows):
netsh interface ip set address "Ethernet0" static 10.0.1.2 255.255.255.0 10.0.1.1
netsh interface ipv6 set address "Ethernet0" static 2001:db8:1::2/64
netsh interface ipv6 add route ::/0 "Ethernet0" 2001:db8:1::1

🌐 6. óra: Ping6, traceroute6, statikus routing

  • ping 2001:db8:2::2 , tracert -6 (Win) / traceroute6 (Linux)
  • Statikus útvonal: ipv6 route 2001:db8:2::/64 2001:db8:12::2 (R1-en) és vissza
  • Ellenőrzés: show ipv6 route, show ipv6 neighbors
🏠 Házi feladat: Bővítsd a topológiát R3-mal és PC3-mal, add meg a statikus útvonalakat!

4. blokk – SLAAC mélyen (2×45’)

🧠 7. óra: SLAAC elmélet és folyamata

  • Stateless Address Autoconfiguration – automatikus, állapotmentes címzés
  • Lépések: Link-Local → DAD → RS → RA → GUA előállítása
  • ICMPv6 típusok: RS(133), RA(134), NS(135), NA(136)
  • EUI-64 (MAC→64 bit) és véletlen címek (RFC 7217, adatvédelem)
  • RA flag-ek: A (autonomous), M (managed), O (other)

🔧 8. óra: SLAAC konfigurálás és ellenőrzés

  • Routeren elég: ipv6 unicast-routing + /64 cím az interfészen → RA automatikus
  • PC: automatikus címkérés (Windows: ipconfig /renew6 ; Linux: accept_ra=1)
  • Ellenőrzés: ip -6 addr show, show ipv6 neighbors
  • Wireshark: RS, RA, NS, NA csomagok megfigyelése
Router (Cisco):
ipv6 unicast-routing
interface g0/0
 ipv6 enable
 ipv6 address 2001:db8:1::1/64

PC (Windows):
netsh interface ipv6 set interface "Ethernet0" routerdiscovery=enabled
ipconfig /release6
ipconfig /renew6
ipconfig   # ellenőrzés

5. blokk – Összefoglaló gyakorlat és mérés (2×45’)

🏆 9. óra: Komplex gyakorlati feladat (3 router, SLAAC + statikus)

Topológia: R1 – R2 – R3 ; LAN1 (R1) – PC_A, PC_B ; LAN2 (R3) – PC_C, PC_D

IPv6 címzési terv:

  • R1–R2: 2001:db8:ab::/64 (R1::1, R2::2)
  • R2–R3: 2001:db8:bc::/64 (R2::1, R3::2)
  • LAN1: 2001:db8:1::/64 – gateway R1: ::1, PC_A, PC_B SLAAC
  • LAN2: 2001:db8:3::/64 – gateway R3: ::1, PC_C: ::10, PC_D: ::11 (statikus)
  1. Router interfészek konfigurálása (IPv4 is lehet mellékesen).
  2. ipv6 unicast-routing minden routeren.
  3. Statikus IPv6 útvonalak (LAN1 ↔ LAN2).
  4. SLAAC beállítása a LAN1-en, ellenőrizd a kapott címet.
  5. PC_C, PC_D statikus cím + gateway.
  6. Ping tesztek: PC_A → PC_C, PC_B → PC_D, PC_A → R2 link-local.
  7. Screenshot: show ipv6 route (R1) és ip -6 addr show (PC_A).

Pontozás (100 pont): Router interfész (15) + routing bekapcsolás (5) + statikus útvonal (20) + SLAAC (15) + statikus PC (10) + ping (15) + screenshot (10) + elmélet (10).

📢 10. óra: Bemutatás, hibaelhárítás, értékelés

  • 2–3 csapat bemutatja a megoldását (topológia, routing, SLAAC, sikeres ping).
  • Közös hibaelhárítás előre elrontott konfiguráción (pl. nincs ipv6 unicast-routing, rossz statikus útvonal, RA suppress).
  • Írásbeli gyorsteszt (5 kérdés).
  • Értékelés, jegyek közlése, zárás.
✍️ Teszt mintakérdések: 1. Tömörítsd: 2001:0db8:0000:0000:0000:0000:0000:0001 → 2001:db8::1 ; 2. Link-Local prefix? → fe80::/10 ; 3. RA típusa? → 134 ; 4. DAD célja? → címütközés elkerülése ; 5. EUI-64 hány bites? → 64 bit

Forma: XXXX:XXXX:XXXX:XXXX:XXXX:XXXX:XXXX:XXXX

2001:0db8:85a3:0000:0000:8a2e:0370:7334

Rövidítés:
1. Vezető nullák elhagyása → 2001:db8:85a3:0:0:8a2e:370:7334
