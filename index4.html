1. blokk – Bevezetés, címzés alapjai (2×45’) – Részletes kifejtés

📘 1. óra: Miért van szükség IPv6-ra?

  • IPv4 kimerülése (IANA 2011, RIR-ek kimerülése), NAT és CGNAT hátrányai (játékok, P2P, port forwarding).
  • IPv6 előnyei: 2128 cím („atomokra is jut”), nincs szükség NAT-re, egyszerűbb fejrész, beépített IPsec, SLAAC.
  • Tévhitek eloszlatása: „bonyolult” → valójában logikusabb; „nem kompatibilis” → duál stack; „lassabb” → routerek kevesebb számítást végeznek.
  • Gyakorlati motiváció: IoT, 5G, okosotthon – minden eszköz kaphat egyedi globális címet.

✏️ 2. óra: IPv6 cím felépítése, rövidítés, tömörítés

  • 128 bit = 8×16 bit → 8 darab hexa csoport kettősponttal (pl. 2001:0db8:85a3:0000:0000:8a2e:0370:7334).
  • Rövidítési szabályok: (1) vezető nullák elhagyása, (2) :: egyszeri használata (csak a leghosszabb nullblokkra).
  • Speciális címek: ::1 (loopback), :: (meghatározatlan), ::ffff:192.0.2.1 (IPv4 leképzett).

2. blokk – Címtípusok és alhálózatképzés (2×45’) – Részletes kifejtés

🎯 3. óra: IPv6 címtípusok

  • Unicast: Global Unicast (2000::/3), Unique Local (fd00::/8), Link-Local (fe80::/10).
  • Anycast: egy a legközelebbihez (pl. root DNS szerverek).
  • Multicast: ff00::/8 – fontos csoportok: ff02::1 (minden node), ff02::2 (minden router).
  • Link-Local címek automatikus létrejötte (ipv6 enable), szerepük: alapértelmezett gateway, RA-k küldése.
  • Bemutató: ipconfig / ip -6 addr show – a fe80::/64 cím megfigyelése.

📐 4. óra: Prefixek és alhálózatképzés

  • CIDR jelölés, ajánlott /64 a legtöbb LAN-ban (SLAAC és EUI-64 miatt).
  • Számítás: 2(új_prefix - régi_prefix) alhálózat. Példa: /48-ból /64 → 216 = 65536 alhálózat.
  • Alhálózati tervező táblázat kitöltése (gyakorlati feladat).

Alhálózati tervező táblázat (minta): 2001:db8:abcd::/48 → első /64-ek

3. blokk – Duál stack, statikus IPv6 routing (2×45’) – Részletes kifejtés

⚙️ 5. óra: Duál stack konfigurálása (routerek, PC-k)

  • Duál stack = IPv4 + IPv6 együtt fut, az alkalmazás preferenciája (RFC 6724 – „Happy Eyeballs”).
  • Topológia: R1 – R2 pont-pont; R1-hez PC1, R2-höz PC2.
  • Router konfiguráció (Cisco): ipv6 unicast-routing, interfészen ipv6 enable és statikus cím.
  • PC-k beállítása statikus IPv6 címmel és alapértelmezett útvonallal (Windows/Linux).
R1 (Cisco):
enable
configure terminal
ipv6 unicast-routing
interface g0/0
 ip address 10.0.1.1 255.255.255.0
 ipv6 enable
 ipv6 address 2001:db8:1::1/64
 no shutdown
interface g0/1
 ip address 10.0.12.1 255.255.255.0
 ipv6 enable
 ipv6 address 2001:db8:12::1/64
 no shutdown

PC1 (Windows):
netsh interface ip set address "Ethernet0" static 10.0.1.2 255.255.255.0 10.0.1.1
netsh interface ipv6 set address "Ethernet0" static 2001:db8:1::2/64
netsh interface ipv6 add route ::/0 "Ethernet0" 2001:db8:1::1

🌐 6. óra: Ping6, traceroute6, statikus routing

  • Ellenőrzés: ping 2001:db8:12::2 (közvetlen), tracert -6 / traceroute6.
  • Statikus útvonalak: ipv6 route 2001:db8:2::/64 2001:db8:12::2 (R1-en) és vissza R2-n.
  • Hibakeresés: show ipv6 route, show ipv6 neighbors, debug ipv6 icmp (csak tesztre).
💡 Tipp: A pont-pont kapcsolatokon érdemes a /127 prefixet is megemlíteni (RFC 6164), de a tantervben a /64 marad az egyszerűség kedvéért.
🏠 Házi feladat: Bővítsd a topológiát R3-mal és PC3-mal, add meg a szükséges statikus útvonalakat!

4. blokk – SLAAC mélyen (2×45’) – Részletes kifejtés

🧠 7. óra: SLAAC elmélet és folyamata

  • Stateless Address Autoconfiguration – automatikus, állapotmentes címzés, nem igényel DHCP szervert.
  • Lépések: Link-Local generálása → DAD → RS → RA → GUA előállítása + DAD ismét.
  • ICMPv6 típusok: RS (133), RA (134), NS (135), NA (136).
  • EUI-64 címképzés (MAC-ból 64 bit, FFFE beillesztés, bit invertálás) és véletlen címek (RFC 7217, adatvédelem).
  • RA flag-ek: A (autonomous), M (managed), O (other) – kombinációk: tiszta SLAAC, SLAAC + állapotmentes DHCPv6, állapotfüggő DHCPv6.

🔧 8. óra: SLAAC konfigurálás és ellenőrzés (gyakorlat)

  • Routeren: ipv6 unicast-routing + interfészen /64 cím (RA automatikusan megy).
  • PC beállítása automatikus címzésre: Windows: netsh int ipv6 set interface "Eth" routerdiscovery=enabled + ipconfig /renew6; Linux: sysctl net.ipv6.conf.eth0.accept_ra=1.
  • Ellenőrzés: ip -6 addr show, alapértelmezett útvonal a router Link-Local címére mutat.
  • Wireshark / tcpdump bemutató: RS, RA, NS, NA csomagok rögzítése.
Router (Cisco):
ipv6 unicast-routing
interface g0/0
 ipv6 enable
 ipv6 address 2001:db8:1::1/64
 no shutdown

PC (Windows):
netsh interface ipv6 set interface "Ethernet0" routerdiscovery=enabled
ipconfig /release6
ipconfig /renew6
ipconfig   # ellenőrzés
🔍 Megfigyelés: A modern OS-ek (Windows 10+, Android, macOS) alapértelmezetten véletlen (RFC 7217) interfész azonosítót használnak az adatvédelem érdekében.

5. blokk – Összefoglaló gyakorlat és mérés (2×45’) – Részletes kifejtés

🏆 9. óra: Komplex gyakorlati feladat (3 router, SLAAC + statikus)

Topológia: R1 – R2 – R3 ; LAN1 (R1) – PC_A, PC_B ; LAN2 (R3) – PC_C, PC_D.

IPv6 címzési terv:

  • R1–R2 pont-pont: 2001:db8:ab::/64 (R1: ::1, R2: ::2)
  • R2–R3 pont-pont: 2001:db8:bc::/64 (R2: ::1, R3: ::2)
  • LAN1 (R1): 2001:db8:1::/64 – R1 gateway: ::1, PC_A, PC_B SLAAC
  • LAN2 (R3): 2001:db8:3::/64 – R3 gateway: ::1, PC_C: ::10, PC_D: ::11 (statikus)
  1. Routerek interfészeinek konfigurálása (IPv4 opcionális).
  2. ipv6 unicast-routing bekapcsolása minden routeren.
  3. Statikus IPv6 útvonalak: R1 → R3 felé a megfelelő next-hop-okkal, R3 → R1 felé vissza.
  4. SLAAC beállítása a LAN1-en: PC_A és PC_B automatikus címzés, ellenőrzés.
  5. PC_C és PC_D statikus címeinek beállítása (pl. 2001:db8:3::10/64).
  6. Ping tesztek: PC_A → PC_C, PC_B → PC_D, PC_A → R2 link-local címe.
  7. Screenshot készítése: show ipv6 route (R1) és ip -6 addr show (PC_A).

Pontozás (100 pont): Router interfész (15) + routing bekapcsolás (5) + statikus útvonal (20) + SLAAC (15) + statikus PC (10) + ping tesztek (15) + screenshot (10) + elméleti kérdések (10).

📢 10. óra: Bemutatás, hibaelhárítás, értékelés

  • 2-3 csapat bemutatja a megoldását (5 perc/csapat): topológia, statikus útvonalak, SLAAC-os PC-k címei, sikeres ping.
  • Közös hibaelhárítás: a tanár kivetít egy előre elrontott konfigurációt (pl. hiányzó ipv6 unicast-routing, RA suppress, rossz statikus útvonal). A diákok azonosítják a hibákat.
  • Írásbeli gyorsteszt (5-10 kérdés – lásd a mintát a mellékletben).
  • Értékelés, jegyek közlése, záró gondolatok (továbblépési lehetőségek: DHCPv6, OSPFv3).
✍️ Teszt mintakérdések:
1. Tömörítsd: 2001:0db8:0000:0000:0000:0000:0000:0001 → 2001:db8::1
2. Melyik prefix jelöli a Link-Local címeket? → fe80::/10
3. Milyen ICMPv6 típus a Router Advertisement? → 134
4. Mi a DAD célja? → Címütközés elkerülése (Duplicate Address Detection)
5. Hány bit az EUI-64-ben a MAC címből képzett rész? → 64 bit
